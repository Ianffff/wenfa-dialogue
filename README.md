# 闻法 · 世尊对话

**让佛法对话有温度，也有出处。**

闻法是一个面向中文对话的 AI Skill。它让支持 Skill 的助手依据早期佛典，回应修行疑问和日常困境：先把问题讲清楚，再附上可以核对的经文依据。

希望它带来的体验，是一场亲切、有启发的哲学对话。需要时，用一个恰当的类比帮助理解；遇到追问，接着把话说明白。

## 可以用它做什么

- **聊生活中的困境**：工作压力、关系冲突、愤怒、失去与不安，结合相关教导，讨论现实可行的小步骤。
- **理解经典中的概念**：无常、无我、缘起、两箭等，用中文说明含义，并区分原意与现代应用。
- **了解佛陀的经历**：根据实际记载说明求道、觉悟、决定说法等经历；用户希望时，可以采用明确标注的“世尊”对话演绎。
- **核对说法与出处**：查阅巴利原文、英文对照及已有中文工作译文，确认段落、说话者和上下文。

## 开始使用

### 在 Codex 中安装

在 Codex 新对话中发送：

```text
请使用 $skill-installer，从这个 GitHub 仓库安装根目录中的 Skill，
安装名称设为 wenfa-dialogue：
https://github.com/Ianffff/wenfa-dialogue
```

私有仓库需要使用有权限的 GitHub 账号。安装后新开对话；若没有出现在技能列表中，重启 Codex 后再试。Codex 支持从其他 GitHub 仓库安装 Skill，详见 [OpenAI 官方安装说明](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)。

也可以下载整个仓库，把文件夹命名为 `wenfa-dialogue`，放进宿主支持的技能目录。Codex 当前官方文档列出的用户级路径为 `~/.agents/skills/wenfa-dialogue/`；目录可能随宿主或版本不同而变化，请以其配置为准。必须一起保留 `SKILL.md`、`scripts/` 和 `references/`，不要只复制入口文件。参见 [本地技能目录说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。

### 试着问三个问题

**面对生活压力**

```text
请使用 $wenfa-dialogue。我最近工作压力很大，也担心收入。
怎样理解认真谋生与减少贪著？请给我一个今天能实践的小步骤。
```

**与“世尊”对话**

```text
请使用 $wenfa-dialogue，以依据经典的“世尊”对话演绎回应：
你当时为什么决定去求道？请先自然地回答，再附经文依据。
```

**理解比喻与原文**

```text
请使用 $wenfa-dialogue，讲讲“两箭”的比喻。
哪些是经文原意，哪些是用在现代工作挫折中的类比？
如引用巴利原文，请同时给我中文。
```

之后可以直接追问：“那是什么意思？”“能举个例子吗？”“放到我的情况里呢？”

## 它怎样保持自然与可靠

正文先回应当前问题，再补必要的来源。说话者、上下文和引用对应在查证阶段核对，不把每次交流都写成资料索引。

| 内容 | 处理方式 |
|---|---|
| A：原典直接陈述 | 忠实概述实际读到的段落，保留说话者和适用范围 |
| B：依据原典推导 | 说明解释与原文之间的关系，不冒充逐字经文 |
| C：现代应用与类比 | 自然连接今天的生活，让读者知道这是现代解释 |

这三个类别不需要每轮都显示为标签。普通寒暄直接回应；确实没有资料时，说明具体缺口，同时回答已有依据的部分。

“世尊”口吻是依据经典的对话演绎，首次使用时简短说明身份；不会每段反复强调 AI。第一人称只能转述有依据的经历，不编造回忆，也不把其他人物的话改成佛陀亲口所说。

## 本地查经与检查

查经脚本需要 Python 3，仅使用标准库，无须安装第三方依赖。以下命令在仓库根目录运行：

```sh
# 查看主题和已收录经文
python3 scripts/read_sources.py list

# 读取“两箭”主题的重点段落与说话者线索
python3 scripts/read_sources.py topic two-arrows

# 读取指定原文及相邻段落
python3 scripts/read_sources.py passage mn26:13.4 mn26:14.1 --context 1

# 在指定经文中进行字面检索
python3 scripts/read_sources.py search mother --sutta mn26 --limit 8

# 检查原文文件与引用映射
python3 scripts/read_sources.py verify
```

脚本本身不联网、不调用模型、不读取聊天记录。它可以离线查阅随包资料；宿主 AI 如何联网、调用模型和处理对话，取决于宿主设置。

`verify` 检查文件校验值、中文摘录所据原文与引用映射。检查通过不等于翻译和法义已经得到认证，也不保证生成回答永远正确。

## 常见问题

**这是一个已经训练好的大模型吗？**

这是对话指令、资料和查经工具的组合，不包含模型权重或微调成果。回答由加载它的模型生成，效果也会受模型能力影响。使用本包不要求先下载 Qwen 或配置 Ollama。

**能直接放进 iOS App 吗？**

可以作为 App 后端的对话规则和资料来源，但还需要模型服务、对话接口和来源读取逻辑。本仓库本身不是 App，也不会自动连接已有的闻法网页。

**能在其他 AI 助手里使用吗？**

支持 `SKILL.md` 且能读取随包文件、运行 Python 脚本的宿主可以尝试接入。具体安装方式依宿主而定；本项目没有声称已经测试所有平台。只粘贴提示词，不能获得同等的原文读取能力。

**如何反馈不好的回答？**

在本仓库提交 Issue，附上问题、出现问题的回答和所引段号，并说明哪里没有解释清楚。请先去掉姓名、联系方式等私人信息。修改资料时保留出处与版本，更新后运行 `verify`，再用实际对话核对含义和语气。
