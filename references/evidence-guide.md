# 证据与表达约定

## 从材料到回答

为准备使用的每个主张确定：谁在说、在回应什么、适用谁、处于哪个时间阶段，以及哪一段实际支持它。正文可以自然，证据对应不能含糊。

| 类别 | 可以怎么表达 | 不可越过的界限 |
|---|---|---|
| A 原典直接陈述 | 忠实概述已读段落；保留说话者、否定和范围 | 中文改写并非历史人物的中文逐字原话；经文记载也不等于现代实证证明 |
| B 依据原典推导 | “由这里可以理解……”或将推导身份放在末尾依据说明 | 推导不能冒称经文直接结论；要说明它如何从所引材料而来 |
| C 现代应用 | “放到你现在的处境……”或“打个今天的比方……” | 不伪造古人谈现代事物；比喻只解释关系，不增添神秘实体或保证结果 |

一段回答可同时含三类，不必逐句标字母。引用的是支撑，不是装饰：只列经名、只验证段号存在、用一个相关段号覆盖所有主张，都不够。

## 第一人称转述

“当时我……”可用于已明示的对话演绎，但每个历史细节仍须有据。忠实转述追求某个目标，不能扩成当时已实现；记载亲属哭泣，不能扩成亲属后来原谅、妻子的具体想法或未见于文本的临别对白。缺少细节时自然交代“这段记载没有留下那次谈话”，接着讲已知部分。亲切不需要填满所有空白。

改写时用下面几个易混点自检；它们是例子，不是可回答问题的封闭清单：

- **MN26求道**：13段说明反思和所求；14.1说明年轻时出家及父母反应。出家行动这一段，不能独自支撑全部求道动机。按需要读取13.1–13.4与14.1，原文省略保留。
- **MN26决定说法**：19段有迟疑；20段含梵天的思惟和请法；21段有悲悯观察和莲花比喻。20.6–20.7的话不可当作佛陀本人原话。追问“为什么后来愿意讲”承接这个决定，不跳回出家动机。
- **SN5.10车喻**：说话者是金刚比丘尼（Vajirā），对方是魔罗。不能写成“我当年用车告诉弟子”，除非在明确不同人物角色中忠实复述。
- **SN36.21感受成因**：开篇转述的“一切源于过去所作”是待讨论并被反驳的观点，不能抽出来当佛陀结论。经文中的古代病因描述不是现代医学诊断。
- **SN36.6两箭**：经中有身体与心理感受的对比。以现代工作受挫或被侮辱解释“第二箭”，属于类比应用；不要把遭遇伤害等同于受害者自己造成，也不要劝其忍受持续伤害。
- **MN72死后问答**：围绕解脱者的特定命题；不能推出整个经藏否定一般再生。关于一般死后生处可另查MN41，不能把两种对象混为一谈。
- **AN8.54、AN4.61、AN4.62在家生活**：有勤奋、财富用途与无债等材料。不能改成“赚钱本身就是贪欲”或“只要认真工作就足够”。现代预算或沟通建议是应用，不是经文逐字清单。

## 原文与中文

`canon/catalog.json` 记录固定版本及每个原始文件的校验值；`canon/chinese.json` 保存工作译文和当时所据原文。巴利MS底本与Sujato英文均按段保留；这不表示两个文件的每段都等长或都没有省略。

巴利中的 `pe`、`…pe…`、空段不能从英文译本反推补成“完整巴利原文”。需要解释被省略内容时另作说明并引用能实际支持的文本。对含多义词的短句，保留关键词；出现底本或译法差异时说明，不把一种译法宣告为唯一字义。

没有缓存中文的段落：读原文和上下文，给谨慎的中文工作译文，必要时说明对照了英译。不能宣称是既有中文译本，也不能以此拒绝整道问题。只引用实际读取过的原文。外部扩查须记录链接和段落；未经浏览的猜测链接不要当作核实。

## 交付前快速复核

1. 开头真的回答了这轮问题，追问没有串题吗？
2. 读者能得到一层新的理解或一个现实可行的行动，而不仅是安慰吗？
3. 第一人称经历、说话者、时间阶段和所引段落逐项对得上吗？
4. 新类比与现代建议会被误当作佛陀逐字话语吗？
5. 只说明实际缺口了吗，有没有把本包缺失夸大成所有经典都没有？

这些检查是编辑工作，不构成独立的巴利语或法义认证，也不设置必须找到专家才可继续的流程。
